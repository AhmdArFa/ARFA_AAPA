# ARFA AAPA

مساعد Business Q&A للـ head manager فقط، في نسخة تجريبية.

## الفكرة في سطر واحد
المدير يسأل بالعربي، والمساعد يجاوب فورا من الداتا، برقم موثق بالمصدر والفترة وتعريف المقياس. ولو الدليل مش كافي، يقول مش عارف، بدل ما يجاوب غلط.

## قرارات ثابتة في النسخة التجريبية
- المستخدم الوحيد: head manager.
- الداتا: خارجية تجريبية ومصنعة، وليست داتا حقيقية من Vo Technology.
- الوصول: قراءة فقط، وجداول وأعمدة مسموحة فقط.
- الحساب: قاعدة البيانات هي اللي بتحسب، مش الموديل.
- لا كتابة، ولا تعديل، ولا حذف، ولا بيانات شخصية.

## التشغيل
```bash
python3 scripts/seed_demo.py
PYTHONPATH=src python3 -m arfa_aapa.cli --demo
PYTHONPATH=src python3 -m arfa_aapa.cli "ايه ايراد الصيانة اخر 30 يوم؟"
```

## واجهة المدير التجريبية
```bash
PYTHONPATH=src python3 -m arfa_aapa.web --port 8000
```
ثم افتح http://127.0.0.1:8000 في المتصفح.
الواجهة محلية فقط، للقراءة فقط، وتعمل على الداتا التجريبية. فيها 4 مؤشرات رئيسية، وأسئلة مقترحة، وبطاقة إجابة توضح هل الإجابة مؤكدة أم امتناع، مع المقياس والفترة والمصدر.

ملاحظة: مجلد `src` هو الكود، ومجلد `data/demo.db` يتولد محليا ولا يرفع على GitHub.

## الهيكل
- `src/arfa_aapa/security.py`: التحقق من الاستعلام قبل التنفيذ.
- `src/arfa_aapa/metrics.py`: المقاييس المعتمدة وتعريف كل مقياس.
- `src/arfa_aapa/agent.py`: توجيه السؤال، وبناء الإجابة الموثقة، وقاعدة الامتناع.
- `src/arfa_aapa/data/`: توليد الداتا التجريبية والاتصال للقراءة فقط.
- `evals/`: الأسئلة الذهبية للاختبار.
- `docs/`: التعريف، والمعمارية، ونقاط المراجعة.

## نقطة الوقوف
هذه النسخة للمراجعة فقط. لا ترفع على GitHub، ولا توصل بداتا حقيقية، إلا بعد موافقة صريحة في نقطة المراجعة.
