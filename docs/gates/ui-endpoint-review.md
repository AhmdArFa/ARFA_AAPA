## ما تم بناؤه
- واجهة ويب عربية، باتجاه RTL، بمكتبة Python القياسية فقط، بلا اعتماديات خارجية.
- تعمل على 127.0.0.1 فقط، للقراءة فقط، وعلى الداتا التجريبية فقط.
- 4 مؤشرات رئيسية عند الفتح: إجمالي الإيراد، إيراد الصيانة، كروت الشغل المفتوحة، متوسط رضا العملاء.
- مربع سؤال بالعربي، مع أسئلة مقترحة قابلة للضغط عليها.
- بطاقة إجابة توضح: مؤكد من الداتا أم امتناع، والمقياس، والفترة، والمصدر، والتعريف.
- نقاط نهاية: GET /api/health، GET /api/kpis، GET /api/questions، POST /api/ask.
